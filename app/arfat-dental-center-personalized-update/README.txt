ARFAT DENTAL CENTER - WEBSITE UPDATE

Copy the app folder and public folder into your existing Next.js project, replacing the existing app and public folders/files where names overlap.

Then run:
npm run dev

Open:
http://localhost:3000

Appointment page:
http://localhost:3000/appointment

Demo admin:
http://localhost:3000/admin
Demo password: arfat123

IMPORTANT:
This first build stores appointments in browser localStorage. It is NOT a production booking backend.
Before launch, connect a real database, secure authentication, server-side booking/slot locking, and WhatsApp Business API.
